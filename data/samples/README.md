# Bundled headline sample

`sample_headlines.csv` is an **illustrative sample authored by the researcher**
to exercise the sentiment-to-report integration end to end. These ten rows are
NOT a market dataset: they were written for this repository, they describe the
same seven tickers used elsewhere in the workbench, and they carry no
evidential weight. They are the only data files tracked in git.

The evidence-bearing sentiment benchmark (Financial PhraseBank, VADER vs
TF-IDF vs MiniLM vs FinBERT) lives in the sibling repository
[`financial-nlp-sentiment`](https://github.com/aydinmonavvari/financial-nlp-sentiment).
